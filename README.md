# Angel Bakery 天使牌

Order page for Angel Bakery's handmade festive cookies and crispy snacks, in English and 中文.

- `angel-bakery.html` — the page: menu, JB gift picks, cart, and Touch 'n Go eWallet QR payment
- `angel-logo.jpg` — logo
- `payment-qr.png` — Touch 'n Go eWallet QR (payee: JMCO Trading)
- `photos/` — product photos, named after each menu item (for example `photos/pineapple-tarts.jpg`)

Customers fill a cart and press **Send order on WhatsApp**: WhatsApp opens a chat to the bakery (016-793 0666) with the order written out. They then pay with the Touch 'n Go QR and send the receipt in the same chat. Nothing is stored on a server, so the page works on any static host, such as GitHub Pages.
